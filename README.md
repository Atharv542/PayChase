## 📌 Overview

**PayChase** is an AI-powered freelance invoice generation platform designed to help freelancers and small businesses manage invoices, clients, and payments efficiently.

The platform allows users to:

* Create professional invoices
* Manage client details
* Download invoices as PDFs
* View analytics on a dashboard
* Use AI-powered productivity features

PayChase simplifies financial workflows and provides a clean, modern, and user-friendly experience.

---

## ✨ Features

### 🧾 Invoice Management

* Create professional invoices
* Add company and client details
* Add multiple services/products
* Automatic total calculations
* Tax & discount support
* Download invoices as PDF

### 👥 Client Management

* Store client information
* Track invoice history per client

### 📊 Dashboard & Analytics

* Revenue overview
* Invoice statistics
* Pending vs completed invoices
* Monthly earnings insights

### 🤖 AI Features

* AI-generated invoice descriptions
* Smart payment reminder generation
* Professional business text suggestions
* Automated content assistance

### 🔐 Authentication

* Secure login/signup system
* User-specific invoice storage
* Protected routes & sessions
